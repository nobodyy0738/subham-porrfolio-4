# Shubham Murari - Personal Portfolio Website

A modern, responsive, high-performance personal portfolio website built with **React**, **Vite**, and **Tailwind CSS**.

## 🚀 Key Highlights & Features
- **Hero Section**: Personal introduction for Shubham Murari (B.Tech CSE Student, JECRC University, Jaipur), dynamic status indicator, quick action buttons ("View Projects", "Connect on LinkedIn"), and interactive code terminal preview.
- **About Me**: Narrative card with student background, 4 core pillars (AI Tools & Exploration, Web Development, Digital Productivity, Practical Projects & Problem Solving), quick stats, and interactive student profile modal.
- **Education**: Detailed card for **B.Tech Computer Science & Engineering at JECRC University, Jaipur**, including core coursework focus in foundational programming and problem solving.
- **Skills**: Interactive skill cards with category filters for: C, Python, HTML, CSS, JavaScript, Web Development, AI Tools, Problem Solving.
- **Projects**: Honest and recruiter-friendly project showcase with interactive modal previews:
  1. Personal Developer Portfolio (Live & Completed)
  2. Python & C Problem Solving Lab (Active Coursework & Practice)
  3. Web App & AI Tools Integration (In Development / Build Slot)
- **Achievements**: Clean milestone showcase highlighting academic enrollment, core logic milestones, web development progress, and target hackathon roadmap.
- **Contact**: Recruiter-friendly contact section with 1-click email copy, direct LinkedIn profile link, and interactive direct message contact form.
- **Design**: Dark & light mode toggle, glassmorphic UI, responsive mobile hamburger drawer navigation, and smooth scrolling.

## 🛠️ Tech Stack
- **Framework**: [React 18](https://react.dev/)
- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 3.4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com/) ready with `vercel.json`

---

## 💻 Local Development Setup

1. Open a terminal in the `portfolio` folder:
   ```bash
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Open `http://localhost:5173` in your browser.

---

## 📦 Production Build

To build the static files for production:
```bash
npm run build
```
The optimized production assets will be generated in the `dist/` directory.

To preview the production build locally:
```bash
npm run preview
```

---

## ☁️ Deploying to Vercel (1-Click)

1. Push your repository to **GitHub**.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Set the **Root Directory** to `portfolio` (if the repo root is parent) or leave default if repo root is the `portfolio` folder.
5. Framework Preset: **Vite**.
6. Click **Deploy**! 🚀
